## 1. 产品概述

### 1.1 产品定位

一款面向 4-12 岁儿童家庭的行为管理工具，通过游戏化的积分激励机制，帮助家长解决孩子拖延、缺乏主动性等问题。

### 1.2 核心价值

**将"做任务→攒积分→换奖励"的游戏机制应用到儿童日常行为管理，通过即时反馈解决拖延症问题。**

孩子不是不想做好，而是缺少即时反馈——积分系统把远处的反馈拉到眼前：今天按时写完作业，现在就能看到积分增加，离想要的奖励又近了一步。

### 1.3 目标用户

| 用户角色 | 描述 |
|----------|------|
| 主要用户 | 4-12 岁儿童家长（管理孩子日常行为） |
| 次要用户 | 4-12 岁儿童（完成任务、查看积分） |

### 1.4 核心场景

- 早上起床拖拉、穿衣慢、吃饭磨蹭
- 写作业坐不住、发呆、需要反复催促
- 练琴、收拾玩具等任务缺乏主动性
- 家长疲惫于每天"吼娃"式管教

## 2. 功能模块

### 2.1 积分任务系统

#### 2.1.1 功能描述

家长发布任务，孩子完成后获得积分奖励。

#### 2.1.2 功能清单

| 功能点 | 优先级 | 描述 |
|--------|--------|------|
| 创建任务 | P0 | 任务名称、积分值、截止时间、重复规则（每日/每周/一次性） |
| 编辑任务 | P0 | 修改任务信息 |
| 删除任务 | P0 | 删除任务 |
| 任务列表 | P0 | 按状态（待完成/已完成/已超时）分类展示 |
| 标记完成 | P0 | 孩子点击完成任务，积分即时增加 |
| 提前完成奖励 | P1 | 提前完成额外加分（可配置百分比） |
| 任务模板 | P2 | 预设常用任务模板（起床、写作业、练琴等） |
| 任务提醒 | P1 | 截止前 N 分钟推送提醒 |

#### 2.1.3 惩罚保护机制

| 规则 | 说明 |
|------|------|
| 缓冲时间 | 超时 10 分钟内不算迟到 |
| 扣分上限 | 每日最多扣 5 分，避免"破产"放弃 |
| 模式开关 | 可关闭扣分功能，纯奖励模式（适合低龄儿童） |

---

### 2.2 心愿奖励系统

#### 2.2.1 功能描述

孩子设定想要的目标奖励，通过积累积分兑换。

#### 2.2.2 功能清单

| 功能点 | 优先级 | 描述 |
|--------|--------|------|
| 创建心愿 | P0 | 心愿名称、所需积分、奖励类型、图片（可选） |
| 心愿列表 | P0 | 展示所有心愿及进度 |
| 进度可视化 | P0 | 显示"已攒 X 分，还差 Y 分"进度条 |
| 申请兑换 | P0 | 孩子积分足够时申请兑换 |
| 家长审批 | P0 | 家长同意/拒绝兑换申请 |
| 兑换记录 | P1 | 历史兑换记录查询 |

#### 2.2.3 奖励分类

| 类型 | 示例 | 特点 |
|------|------|------|
| 物质类 | 玩具、零食、文具 | 需要花钱购买 |
| 精神类 | 看动画片、去公园、和爸爸下棋 | 时间/陪伴型奖励 |
| 特权类 | 今天不用洗碗、自己安排周末半天 | 权利让渡型奖励 |

---

### 2.3 专注训练

#### 2.3.1 功能描述

类似简化版番茄钟，帮助孩子培养专注力，解决写作业坐不住的问题。

#### 2.3.2 功能清单

| 功能点 | 优先级 | 描述 |
|--------|--------|------|
| 简单模式 | P0 | 10/15/20 分钟单次专注 |
| 番茄钟模式 | P0 | 25 分钟专注 + 5 分钟休息，可多轮 |
| 倒计时显示 | P0 | 大圆环倒计时动画 |
| 暂停/继续 | P1 | 支持暂停（可限制次数） |
| 放弃专注 | P1 | 允许中途放弃（可配置是否禁用） |
| 完成自评 | P0 | 1-5 星评分，星星数 = 积分数 |
| 满分奖励 | P1 | 5 星额外 +1 分 |
| 训练统计 | P2 | 今日/本周专注时长统计 |

#### 2.3.3 家长配置项

| 配置项 | 说明 |
|--------|------|
| 每日训练上限 | 防止刷分 |
| 积分倍率 | 调整专注积分产出 |
| 禁止退出 | 开启后中途无法放弃 |

### 2.4 语音鼓励系统

#### 2.4.1 功能描述

在关键节点自动播放语音，给孩子即时正向反馈。

#### 2.4.2 触发场景

| 场景 | 时机 | 话术示例 |
|------|------|----------|
| 专注开始 | 开始专注训练 | "专注训练开始，加油哦！" |
| 过半提醒 | 时间过半 | "已经过半了，继续保持！" |
| 剩余提醒 | 剩余 5 分钟 | "还剩 5 分钟，坚持住！" |
| 最后冲刺 | 剩余 1 分钟 | "最后 1 分钟，马上就完成了！" |
| 专注完成 | 训练结束 | "太棒了，专注训练完成！" |
| 满分评价 | 打了 5 星 | "满分！你是最棒的！" |
| 任务提前完成 | 提前完成任务 | "太厉害了！提前完成，获得额外奖励积分！" |
| 任务按时完成 | 按时完成 | "做得好！继续保持哦！" |
| 任务迟完成 | 迟到但完成 | "虽然晚了一点，但坚持完成也很棒！下次加油！" |

#### 2.4.3 配置项

| 配置项 | 说明 |
|--------|------|
| 语音开关 | 可关闭语音 |
| 音量调节 | 调整语音音量 |
| 话术自定义 | P2 版本：家长可自定义话术 |

### 2.5 作业批改

#### 2.5.1 功能描述

拍照上传作业，AI 自动批改并识别错题。

#### 2.5.2 功能清单

| 功能点 | 优先级 | 描述 |
|--------|--------|------|
| 拍照上传 | P0 | 调用相机拍摄作业 |
| 选择科目年级 | P0 | 科目（语文/数学/英语）+ 年级 |
| AI 批改 | P0 | 识别总题数、正确数、错误数 |
| 错题详情 | P0 | 每道错题：题目、孩子答案、正确答案、解析、知识点 |
| 批改历史 | P1 | 历史批改记录查询 |

#### 2.5.3 注意事项

- AI 批改仅供参考，字迹潦草/图片模糊可能误判
- 不完全替代家长检查，作为第一轮筛查工具

## 3. 非功能需求

### 3.1 性能需求

| 指标 | 要求 |
|------|------|
| 页面加载 | 首屏加载 < 2 秒 |
| 操作响应 | 点击响应 < 300ms |
| 语音播放 | 触发后 < 500ms 播放 |

| 需求 | 说明 |
|------|------|
| 数据加密 | 敏感数据（密码、个人信息）加密存储 |
| 传输加密 | HTTPS 传输 |
| 隐私保护 | 儿童照片不存储原图，批改后即删除 |

### 3.3 兼容性需求

| 平台 | 要求 |
|------|------|
| 微信小程序 | 支持微信最新 3 个主版本 |
| iOS | iOS 13.0+ |
| Android | Android 8.0+ |

## 4. 数据埋点

### 4.1 核心指标

| 指标 | 定义 | 用途 |
|------|------|------|
| DAU | 日活跃用户数 | 产品健康度 |
| 任务完成率 | 完成任务数 / 发布任务数 | 核心价值验证 |
| 7 日留存 | 注册 7 天后仍活跃的用户占比 | 用户粘性 |
| 心愿兑换率 | 兑换心愿数 / 创建心愿数 | 激励有效性 |
| 专注训练使用率 | 使用专注训练的用户占比 | 功能价值 |

### 4.2 行为埋点

| 事件名称 | 触发时机 |
|----------|----------|
| task_create | 创建任务 |
| task_complete | 完成任务 |
| wish_create | 创建心愿 |
| wish_redeem | 兑换心愿 |
| focus_start | 开始专注训练 |
| focus_complete | 完成专注训练 |
| homework_scan | 扫描作业 |
| theme_change | 切换主题 |
