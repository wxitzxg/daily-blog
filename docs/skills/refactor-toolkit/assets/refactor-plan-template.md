## API 映射表（框架迁移专用）

| 源 API | 目标 API | 注意事项 |
|--------|----------|----------|
| app.get() | hono.get() | - |
| req.body | c.req.json() | 需 await |
| req.params | c.req.param() | - |
| res.json() | c.json() | 状态码放第二个参数 |

## Wave 划分（大规模重构专用）

### Wave 1（并行执行）

| Agent | 文件所有权 | 任务 |
|-------|-----------|------|
| router-agent | src/routes/ | 路由迁移 |
| middleware-agent | src/middleware/ | 中间件适配 |

### Wave 2（依赖 Wave 1）

| Agent | 文件所有权 | 任务 |
|-------|-----------|------|
| test-agent | tests/ | 测试更新 |

## 风险与缓解

| 风险 | 可能性 | 影响 | 缓解措施 |
